เอเจนท์ที่สร้างโดย Google

Deep Research

ลดเวลาวิจัยจากสัปดาห์เหลือเพียงไม่กี่ชั่วโมงด้วย Deep Research เอเจนท์นี้จะใช้การคิดเชิงเหตุผล วางแผน และทำการค้นหาข้อมูลนับร้อยรายการผ่านเว็บและข้อมูลองค์กร พร้อมสร้างรายงานสรุปที่ครอบคลุม

Data Insights (Preview)

เปลี่ยนสเปรดชีตที่ซับซ้อนให้เป็นข้อมูลเชิงลึกที่นำไปใช้ได้จริง เอเจนท์นี้ให้ข้อมูลเชิงลึกจากข้อมูล BigQuery ของคุณโดยไม่ต้องมีความรู้ด้าน SQL มาก่อน ช่วยให้นักวิเคราะห์ข้อมูลมีเวลาโฟกัสกับงานที่ซับซ้อนมากขึ้น

NotebookLM Enterprise

เร่งการแชร์ความรู้ในทีมด้วย NotebookLM Enterprise เครื่องมือวิจัยและเขียนที่ขับเคลื่อนด้วย AI ซึ่งช่วยคุณสรุปและดึงข้อมูลจากแหล่งข้อมูลที่หนาแน่นและซับซ้อน

Gemini Code Assist

ช่วยให้นักพัฒนาทำงานทั่วไปได้สำเร็จรวดเร็วขึ้น เอเจนท์เฉพาะทางนี้ช่วยนักพัฒนาทำงานเขียนโค้ดตลอดวงจรการพัฒนาซอฟต์แวร์

สร้างเอเจนท์ของคุณเอง

Agent Designer

ให้พนักงานทุกคนเปลี่ยนความเชี่ยวชาญของตนเองเป็น "ผู้ช่วย AI" โดยใช้ Agent Designer แบบ no-code เครื่องมือนี้จะเปลี่ยนความรู้เฉพาะตัวของทีมให้เป็นกระบวนการอัตโนมัติที่ขยายขนาดได้ โดยไม่ต้องเขียนโค้ดแม้แต่บรรทัดเดียว

Agent Studio & ADK

สร้างเอเจนท์ที่กำหนดเองโดยใช้ Agent Studio ใหม่หรือ Agent Development Kit (ADK) และกำกับดูแลผ่านแอป Gemini Enterprise แพลตฟอร์มเอเจนท์นี้เป็นจุดหมายเดียวสำหรับทีมเทคนิคของคุณ ในการสร้างเอเจนท์ที่กำหนดเองอย่างปลอดภัยโดยใช้โมเดลที่คุณเลือกสำหรับอุตสาหกรรมและธุรกิจของคุณ

External Platforms (A2A)

อัปโหลด เข้าถึง ปรับใช้ และกำกับดูแลเอเจนท์ที่คุณสร้างขึ้นบนแพลตฟอร์มภายนอก เรานำอุตสาหกรรมด้วยมาตรฐานเปิด เช่น โปรโตคอล Agent2Agent (A2A) เพื่อให้แน่ใจว่าเอเจนท์สามารถสื่อสารและทำงานร่วมกันได้โดยไม่คำนึงถึงโมเดลหรือแพลตฟอร์มพื้นฐาน

*พร้อมใช้งานในรุ่น Standard และ Plus ของแอป Gemini Enterprise

Agent Marketplace
